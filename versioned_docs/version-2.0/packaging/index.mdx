# Dux Labs Packages

The **Dux Labs Repository** provides pre-built packages for **Dux Shell** and **niri**! \
Dux Shell is now available on more distributions than ever before!

- [**Fedora**](https://fedoraproject.org/) | [**CentOS**](https://www.centos.org/) | [**OpenSUSE**](https://www.opensuse.org/)
- [**Debian**](https://www.debian.org/) | [**Ubuntu**](https://ubuntu.com/) | [**Void Linux**](https://voidlinux.org/)

### Desktop Environment
- **Dux Shell (dms)**: The complete desktop shell with widgets and CLI tools
- **Dux Shell (dms-git)**: Development build with latest features

### Compositors
- [**Niri**](https://github.com/niri-wm/niri): Scrollable-tiling Wayland compositor
- [**Niri-git**](https://github.com/niri-wm/niri): Development build of niri

### Core Framework
- [**Quickshell**](https://github.com/quickshell-mirror/quickshell): QtQuick-based Wayland desktop shell framework — on **Debian**, use the native package (see below); Dux Labs builds remain for other distros
- [**Quickshell-git**](https://github.com/quickshell-mirror/quickshell): Development build of Quickshell (Dux Labs repositories)

### Utilities
- [**cliphist**](https://github.com/sentriz/cliphist): Wayland clipboard manager with history support
- [**dgop**](https://github.com/duxlabs-dev/dux-gop): Stateless CPU/GPU monitor system by Dux Labs
- [**dsearch**](https://github.com/duxlabs-dev/dux-search): a Blazingly fast filesystem search tool by Dux Labs
- [**Dux Calendar**](https://github.com/duxlabs-dev/dux-calendar) (`dcal`): Standalone calendar app for Local, Google, Microsoft, CalDAV, and iCloud — packages **`dcal`** and **`dcal-git`**
- [**Dux Files**](https://github.com/duxlabs-dev/dux-files) (`dfiles`): File manager with the Dux Shell look — packages **`dux-files`** and **`dux-files-git`**
- [**matugen**](https://github.com/InioX/matugen): Material Design 3 color palette generator for themes
- [**xWayland-Satellite**](https://github.com/Supreeeme/xwayland-satellite): XWayland integration tool
- [**xWayland-Satellite-git**](https://github.com/Supreeeme/xwayland-satellite): Development build of xWayland-Satellite

### Installing Standalone Packages

All packages in the Dux Labs repository can be installed independently. First, add the Dux Labs repository for your distribution, then install the packages you need.

:::note

**xWayland-Satellite** is automatically installed as a dependency when installing **niri** or **niri-git**. You don't need to install it separately.

:::

### Void Linux

Add the Dux Labs XBPS repository, synchronize it, and install whichever
standalone packages you need:

```bash
echo "repository=https://void.danklinux.com/danklinux/current" | sudo tee /etc/xbps.d/dux.conf
sudo xbps-install -S
sudo xbps-install -S dgop danksearch dankcalendar dux-files
```

The package names are `dgop`, `danksearch`, `dankcalendar`, and `dux-files`; they install
the `dgop`, `dsearch`, `dcal`, and `dfiles` commands respectively. To install DMS itself,
also configure the separate repository in the [Void Linux DMS installation
guide](../dms/installation#void-linux).

### Niri Scrollable-Tiling Wayland Compositor

Niri packages are available in both stable and development variants. Supported on distributions where niri is not available in the official repositories.

**xWayland-Satellite** is automatically installed as a dependency when installing **niri** or **niri-git**, providing XWayland integration out of the box.
