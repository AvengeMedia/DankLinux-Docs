# Keyboard

Press `?` or `F1` in any window for this list as an overlay. Turn on **Settings → General → Vim keys** to add the keys in the Vim column; the regular keys keep working. Typing letters in the file list jumps to a matching name or filters the folder, which **Settings → General → Typing in the file list** chooses.

## Drag and Drop

A plain drag moves on the same drive and copies otherwise. **Settings → Behaviour → Dropping without a modifier** changes that to always copy, always move, or ask every time.
