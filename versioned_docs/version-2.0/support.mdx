## Community Support

Report bugs, request features, or browse existing issues:

- [Dux Shell Issues](https://github.com/duxlabs-dev/dux-shell/issues)
- [dgop Issues](https://github.com/duxlabs-dev/dux-gop/issues)
- [dsearch Issues](https://github.com/duxlabs-dev/dux-search/issues)

### Discord

`Dux Shell` has a subsection on the niri discord server, keep relevant discussions in the relevant `#dms-*` channels.

**Discord Server:** [niri discord](https://discord.gg/ppWTpKmPgT)

### Bug Reports

When reporting bugs, please include:

- Your Linux distribution and version
- Dux component versions
- Steps to reproduce the issue
- Expected vs. actual behavior
- Relevant logs or error messages
