我们很高兴地宣布 DankMaterialShell (DMS) 1.0 发布！~ DMS 是一个使用 [Quickshell](https://quickshell.org/) 和 GO 构建的 Wayland 合成器桌面 Shell。

这个最初只是小型爱好项目的作品，如今已成长为拥有数千用户和数十位贡献者的完整桌面 shell 和应用程序套件——为 [niri](https://github.com/niri-wm/niri)、[Hyprland](https://hypr.land)、[Sway](https://swaywm.org)、[MangoWC](https://mangowc.vercel.app/) 和 [LabWC](https://labwc.github.io/) 提供一流支持，并普遍支持所有实现了特定 Wayland 协议的合成器。

DMS 自诞生以来已经走过了漫长的道路，我们很高兴转向更结构化的开发流程——这是让 DMS 成为主流 Linux 桌面项目的一步。

## 不只是一个 Shell {#more-than-just-a-shell}

DMS 已经不仅仅是一个桌面 shell。它是一套全面的工具，以连贯、集成的方式提供核心桌面功能——或作为完全独立的实用程序来丰富非 DMS 桌面。


- **DankMaterialShell (qml)** - shell 中基于 quickshell 的部分
- **DankMaterialShell (go)** - 全面的后端服务和工具套件
  - **Dank16** - 适用于 Base16 风格主题的对比度感知调色板生成器
  - **Matugen** - 自定义 matugen 运行器，用 Dank16 和自定义颜色丰富 matugen 模板
  - **Brightness** - 用于背光、LED 和 ddc/ci 亮度控制的完整管理 CLI 和套接字服务。
  - **Networking** - 与 NetworkManager、IWD 和 systemd-networkd 的原生 dbus 集成，提供全面的网络管理——包括 VPN、WiFi 和以太网。
  - **Keybinds** - 完整的按键绑定系统，带有可插拔的提供程序，用于读取和写入备忘单和管理界面的按键绑定。
  - **Color Picker** - 带多种输出格式的 CLI 取色器和 Wayland 吸管工具。
  - **Screenshot** - 完整的截图工具，支持区域选择、窗口捕获和多种输出格式。
  - **Plugins** - 用于通过自定义功能扩展 shell 和启动器的插件系统。
- **dgop** - 无状态系统监控工具，采用独特的基于游标的方式。CLI 和完整文档（OpenAPI 3.1）的 REST API。
- **dsearch** - 极速、带增量索引的索引式文件系统搜索服务器。完全可配置——选择深度、文件夹、排除项、元数据、内容等。CLI、Unix Socket 和 Rest API。

**TL;DR** *DMS* 取代了许多 Wayland 桌面常用的工具。不再需要 `brightnessctl`、`ddcutil`、`grimblast`、`nmcli`、`iwctl`、`grim`、`slurp`、`wofi`、`fuzzel`、`swayidle`、`hyprlock`、`mate/gnome/kde polkit`、`mako/dunst`、`hyprpicker`、`sddm`（以及一大堆其他工具）。完全可选，并完全独立于 DMS 本身。

自上次 v0.6.2 发布以来，DMS 在所有组件中进行了大量的错误修复和稳定性改进：

**截图和取色器**
- 处理来自合成器的 24 位帧和 RGB888 位翻转
- 色彩空间和缩放修复
- 处理变换和多显示器显示
- 吸管工具的保存按钮显示修复
- 在 niri 上回退到 niri 选择器

**栏和 Dock**
- 中间区域定位和边框粗细修复
- 隐私指示器背景颜色对齐

- 不透明度绑定和提前返回修复

- 屏幕更改时的 IPC 可靠性
- 自动隐藏闪烁和弹出交互修复

**显示和监视器**
- 工作区概述截断和缩放（Hyprland）
- 物理与逻辑分辨率显示
- 监视器小部件中的图标垂直对齐

**音频和媒体**
- 控制中心中的音频滑块绑定
- 输出设备切换 IPC 和 OSD
- 媒体控制列定位（栏感知）
