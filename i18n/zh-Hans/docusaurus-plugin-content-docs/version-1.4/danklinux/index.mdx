## 概览 {#overview}

**DankLinux 软件仓库**为 **DankMaterialShell** 和 **niri** 提供预构建软件包！\
DankMaterialShell 现在比以往任何时候都支持更多发行版！

- [**Fedora**](https://fedoraproject.org/) | [**CentOS**](https://www.centos.org/) | [**OpenSUSE**](https://www.opensuse.org/) 
- [**Debian**](https://www.debian.org/) | [**Ubuntu**](https://ubuntu.com/)

### 桌面环境 {#desktop-environment}
- **DankMaterialShell (dms)**：带小部件和 CLI 工具的完整桌面 shell
- **DankMaterialShell (dms-git)**：包含最新功能的开发构建

### 合成器 {#compositors}
- [**Niri**](https://github.com/niri-wm/niri)：可滚动平铺的 Wayland 合成器
- [**Niri-git**](https://github.com/niri-wm/niri)：niri 的开发构建

### 核心框架 {#core-framework}
- [**Quickshell**](https://github.com/quickshell-mirror/quickshell)：基于 QtQuick 的 Wayland 桌面 shell 框架
- [**Quickshell-git**](https://github.com/quickshell-mirror/quickshell)：Quickshell 的开发构建

### 实用程序 {#utilities}
- [**cliphist**](https://github.com/sentriz/cliphist)：支持历史记录的 Wayland 剪贴板管理器
- [**dgop**](https://github.com/AvengeMedia/dgop)：Avenge Media 出品的无状态 CPU/GPU 监控系统
- [**dsearch**](https://github.com/AvengeMedia/danksearch)：Avenge Media 出品的极速文件系统搜索工具
- [**matugen**](https://github.com/InioX/matugen)：用于主题的 Material Design 3 调色板生成器
- [**xWayland-Satellite**](https://github.com/Supreeeme/xwayland-satellite)：XWayland 集成工具
- [**xWayland-Satellite-git**](https://github.com/Supreeeme/xwayland-satellite)：xWayland-Satellite 的开发构建

## 如何安装 {#how-to-install}

### 安装 DankMaterialShell (DMS) {#installing-dankmaterialshell-dms}

有关包括软件仓库设置在内的完整 DMS 安装说明，请参阅 [DankMaterialShell 安装指南](../dankmaterialshell/installation)。

:::tip[快速开始]

- **Fedora**：请参阅安装指南中的 [Fedora 和 CentOS](../dankmaterialshell/installation#fedora--centos) 部分
- **Ubuntu/Debian**：请参阅安装指南中的 [Ubuntu 和 Debian](../dankmaterialshell/installation#debian--ubuntu) 部分

:::

### 安装独立软件包 {#installing-standalone-packages}

DankLinux 仓库中的所有软件包都可以独立安装。首先为您的发行版添加 DankLinux 仓库，然后安装所需的软件包。

:::note

安装 **niri** 或 **niri-git** 时，**xWayland-Satellite** 会作为依赖项自动安装。您无需单独安装。

:::

### Debian {#debian}

**Debian 13 (Trixie)**：

```bash
# Add DankLinux repository
curl -fsSL https://download.opensuse.org/repositories/home:AvengeMedia:danklinux/Debian_13/Release.key | \
  sudo gpg --dearmor -o /etc/apt/keyrings/danklinux.gpg
echo "deb [signed-by=/etc/apt/keyrings/danklinux.gpg] https://download.opensuse.org/repositories/home:/AvengeMedia:/danklinux/Debian_13/ /" | \
  sudo tee /etc/apt/sources.list.d/danklinux.list
sudo apt update

# Install stable packages
sudo apt install quickshell niri

# Or install development packages
sudo apt install quickshell-git niri-git
```

### Fedora 和 CentOS {#fedora--centos}

COPR 仓库为 Fedora 41/42/43 rawhide 和 CentOS 10 提供软件包：

```bash
# Add DankLinux COPR
sudo dnf copr enable avengemedia/danklinux

# Install stable packages
sudo dnf install quickshell niri

# Or install development packages
sudo dnf install quickshell-git niri-git
```

:::note

软件包可用性因发行版而异。某些软件包可能仅通过 OBS/PPA 在 Debian、Ubuntu 和 OpenSUSE 上可用。

:::

### Niri 可滚动平铺 Wayland 合成器 {#niri-scrollable-tiling-wayland-compositor}

Niri 软件包有稳定版和开发版两种变体。在官方仓库中没有 niri 的发行版上受支持。

安装 **niri** 或 **niri-git** 时，**xWayland-Satellite** 会作为依赖项自动安装，开箱即用地提供 XWayland 集成。

[**Wiki**](https://yalter.github.io/niri/) | [**GitHub**](https://github.com/niri-wm/niri)
