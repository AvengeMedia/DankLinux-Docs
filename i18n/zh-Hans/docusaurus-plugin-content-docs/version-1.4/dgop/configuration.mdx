对于 API，您可以设置以下环境变量来覆盖 http 服务器的端口：
- `API_PORT`（默认为`63484`）

## 按键绑定 {#keybinds}

交互式 TUI 从 `~/.config/dgop/keybinds.json` 读取按键绑定。该文件是在首次运行时使用默认值创建的，并且在 dgop 运行时热重新加载更改。

自定义键是**附加**：您设置的任何键都会添加到内置默认值之上，因此默认的箭头/vim 键将继续工作。这样可以轻松添加替代键盘布局（例如 Colemak-DH）的绑定，而不会丢失默认值。

每个操作都映射到一个键列表。特殊键使用名称 `up`、`down`、`left`、`right`、`enter`、`esc` 以及 `ctrl+c` 等修饰符。

默认`keybinds.json`：

```json
{
  "quit": ["q", "ctrl+c"],
  "refresh": ["r"],
  "details": ["d"],
  "kill": ["x"],
  "group": ["g"],
  "sortCPU": ["c"],
  "sortMemory": ["m"],
  "sortName": ["n"],
  "sortPID": ["p"],
  "navUp": ["up", "k"],
  "navDown": ["down", "j"],
  "selectLeft": ["left", "h"],
  "selectRight": ["right", "l"],
  "confirm": ["enter"],
  "cancel": ["esc", "escape"]
}
```

### 行动 {#actions}

|行动|描述 |
| --- | --- |
| `quit` |退出途易 |
| `refresh` |强制数据刷新 |
| `details` |切换流程详细信息面板 |
| `kill` |打开所选进程的终止确认 |
| `group` |切换子进程分组 |
| `sortCPU` |按 CPU 使用率对进程进行排序 |
| `sortMemory` |按内存使用情况对进程进行排序 |
| `sortName` |按名称对进程进行排序 |
| `sortPID` |按 PID 对进程进行排序 |
| `navUp` / `navDown` |上/下移动流程选择 |
| `selectLeft` / `selectRight` |在终止确认中的选项之间移动 |
| `confirm` |确认击杀动作|
| `cancel` |驳回击杀确认 |

### 示例：Colemak-DH 导航 {#example-colemak-dh-navigation}

添加布局的主行键以进行导航。默认值（`j`/`k`，箭头）仍然与它们一起工作：

```json
{
  "navUp": ["e"],
  "navDown": ["n"]
}
```

您只需要包含要扩展的操作 - 省略的操作保留其默认值。
