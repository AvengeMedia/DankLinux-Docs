## 如何贡献 {#how-to-contribute}

### 报告问题 {#reporting-issues}

发现错误或有功能请求？请在相关存储库上打开问题：

- [DankMaterialShell 问题](https://github.com/AvengeMedia/DankMaterialShell/issues)
- [dgop 问题](https://github.com/AvengeMedia/dgop/issues)
- [dsearch问题](https://github.com/AvengeMedia/danksearch/issues)

### 拉取请求 {#pull-requests}

1. Fork 软件仓库
2.创建功能分支：`git checkout -b feature/my-feature`
3. 做出改变
4. 彻底测试
5. 提交明确的信息：`git commit -m "<component/area>: new feature description"`
6. 推送到你的叉子：`git push origin feature/my-feature`
7. 打开拉取请求

### 代码风格 {#code-style}

- **Go**：遵循标准 Go 格式（`go fmt`、`make fmt`）
- 包括适当的测试覆盖范围
- 修复 lint 错误 `golangci-lint run`
- **TypeScript/JavaScript**：使用一致的格式
- **文档**：使用清晰、简洁的语言

## 社区准则 {#community-guidelines}

尊重所有论坛，例如 GitHub 讨论、discord 等。

- 尊重和包容
- 尽可能帮助别人
- 记录你的代码
- 保持讨论主题

## 支持该项目 {#support-the-project}

想要支持 Dank Linux 开发吗？考虑给我们小费：

[**关于 Ko-fi 的提示**](https://ko-fi.com/danklinux) 🥃

任何类型的贡献 - 代码、文档、错误报告或金钱 - 都将受到赞赏！

## 许可证 {#license}

所有 Dank Linux 项目均根据 MIT 许可证获得许可。通过贡献，您同意在同一许可证下许可您的贡献。

## 获取帮助 {#getting-help}

- **Discord**：`DankMaterialShell` 在 niri Discord 服务器上有一个小节，请在相关 `#dms-*` 频道中保留相关讨论。
- [niri Discord](https://discord.gg/ppWTpKmPgT)
- **GitHub 讨论**：提出问题并分享想法
- **文档**：首先检查这些文档
