# 获取支持 {#support}

## 文档 {#documentation}

建议先查阅我们的文档：

- [快速入门](/docs/getting-started) — 安装与初始设置指南
- [DankMaterialShell](/docs/dankmaterialshell/overview) — Shell 配置与自定义
- [dgop](/docs/dgop) — 系统监控工具
- [dsearch](/docs/danksearch) — 文件系统索引与搜索
- [dankinstall](/docs/dankinstall) — 安装与管理工具

## 社区支持 {#community-support}

### GitHub {#github}

报告错误、提交功能建议或浏览现有问题：

- [DankMaterialShell Issues](https://github.com/AvengeMedia/DankMaterialShell/issues)
- [dgop Issues](https://github.com/AvengeMedia/dgop/issues)
- [dsearch Issues](https://github.com/AvengeMedia/danksearch/issues)

### Discord {#discord}

`DankMaterialShell` 在 niri Discord 服务器中设有专属分区，请在对应的 `#dms-*` 频道讨论相关内容。

**Discord 服务器：** [niri Discord](https://discord.gg/ppWTpKmPgT)

### 错误报告 {#bug-reports}

报告错误时，请提供：

- Linux 发行版及版本
- Dank Linux 各组件的版本
- 问题复现步骤
- 预期行为与实际行为
- 相关日志或错误信息

## 支持项目 {#support-the-project}

如果 Dank Linux 对你有帮助，并希望支持项目继续发展，可以考虑赞助我们：

[**通过 Ko-fi 赞助**](https://ko-fi.com/danklinux) 🥃

你的支持能帮助我们持续开发和维护 Dank Linux 及其所有组件。
