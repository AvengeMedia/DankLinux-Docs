# DGOP安装 {#dgop-installation}

:::note

`dgop` 具有零依赖性并编译为单个静态二进制文件。

:::

### 分发包 {#distribution-packages}

### Arch Linux 及其衍生版 {#arch--derivatives}

<Tabs>
<TabItem value="stable" label="Stable Release" default>

```bash

```

</TabItem>
<TabItem value="git" label="Latest Development Build">


</TabItem>
</Tabs>

```bash
sudo dnf copr enable avengemedia/danklinux
sudo dnf install dgop
```

### Void Linux {#void-linux}

:::note

从我们的 R2 支持的 XBPS 存储库安装 dgop 或从源代码构建它。

:::

:::warning[存储库迁移]

替换现有存储库文件中的旧 URL：

```bash
sudo sed -i 's|https://avengemedia.github.io/DankLinux/current|https://void.danklinux.com/danklinux/current|' /etc/xbps.d/danklinux.conf
```

冻结的 GitHub Pages 存储库不再接收更新，并将被
**2026 年 7 月 24 日 22:27 UTC** 后退休。

:::

<Tabs groupId="void-install-method">
<TabItem value="repo" label="DankLinux Repository" default>

```bash
echo "repository=https://void.danklinux.com/danklinux/current" | sudo tee /etc/xbps.d/danklinux.conf
sudo xbps-install -Su
sudo xbps-install -S dgop
```

:::note

第一次同步时，`xbps-install` 将输出我们的签名密钥指纹，并要求您输入 `y` 以信任并导入它。验证密钥是否与我们的官方签名指纹匹配。

:::

</TabItem>
<TabItem value="source" label="Build from Source">

如果您更喜欢使用 `xbps-src` 从源代码构建：

```bash
# Set up the Void packages tree (one time)
git clone --depth 1 https://github.com/void-linux/void-packages.git
cd void-packages
./xbps-src binary-bootstrap

# Copy in the templates (adjust paths as needed)
cp -R ../DankLinux/distro/void/srcpkgs/dgop* srcpkgs/

# Build the package
./xbps-src pkg dgop

# Install the results
sudo xbps-install --repository=hostdir/binpkgs dgop
```

</TabItem>
</Tabs>

#### Gentoo {#gentoo}

`gui-apps/dgop` 可在官方 [guru](https://wiki.gentoo.org/wiki/Project:GURU) 社区界面中找到。

```bash
sudo eselect repository enable guru
sudo emaint sync -r guru
sudo emerge --ask gui-apps/dgop
```

:::note

guru 覆盖包的关键字为 `~amd64`，因此您可能需要接受测试关键字：

```bash
echo "gui-apps/dgop ~amd64" | sudo tee -a /etc/portage/package.accept_keywords/dgop
```

:::

### 预构建的二进制文件 {#pre-built-binaries}

下载适合您的架构的最新版本：

```bash
# Download and install
wget https://github.com/AvengeMedia/dgop/releases/latest/download/dgop-linux-amd64.gz
gunzip dgop-linux-amd64.gz
chmod +x dgop-linux-amd64
sudo mv dgop-linux-amd64 /usr/local/bin/dgop
```

### 从源代码构建 {#from-source}

要求：Go 1.24+

```bash
git clone https://github.com/AvengeMedia/dgop
cd dgop
make
sudo make install
```

## 验证 {#verification}

测试安装：

```bash
# Check version
dgop version

# Get system metrics
dgop system

# Run API server
dgop server

# See available commands
dgop --help
```

## 系统要求 {#system-requirements}

- **操作系统**：Linux（使用 `/proc` 和 `/sys` 文件系统）
- **Go 版本**：1.24+（用于从源代码构建）

### 可选依赖项 {#optional-dependencies}

对于增强功能：

- `nvidia-smi` - NVIDIA GPU 监控

## 与 DMS 集成 {#integration-with-dms}
