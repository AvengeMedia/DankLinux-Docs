# DankCalendar 安装 {#dankcalendar-installation}

DankCalendar 安装单个 `dcal` 二进制文件、Quickshell UI 配置和桌面条目。

## 要求 {#requirements}

- [Quickshell](https://quickshell.org) (`qs`) — 来自 [DankLinux 存储库](../danklinux/) 的 `quickshell-git` 或 `quickshell`
- Qt 6 声明式，包括用于托盘图标的 `Qt.labs.platform`
- Go 1.25+（仅从源代码构建；打包的二进制文件是纯 Go，没有 CGO）

## 安装方法 {#installation-methods}

选择最适合您的系统的安装方法。

### 扁平包装 {#flatpak}

DankCalendar 在 [Flathub](https://flathub.org/apps/com.danklinux.dankcalendar) 上可用，名称为 `com.danklinux.dankcalendar`。 Flatpak 捆绑了其运行时依赖项，因此您不需要在主机上单独安装 Quickshell。

```bash
flatpak install flathub com.danklinux.dankcalendar
flatpak run com.danklinux.dankcalendar
```

:::note

通知和凭据使用 XDG 桌面门户。要从主机同步 [DankMaterialShell](../dankmaterialshell/overview) 主题颜色，请授予对缓存的读取访问权限：

```bash
flatpak override --user \
  --filesystem=xdg-cache/DankMaterialShell:ro \
  com.danklinux.dankcalendar
```

本地 ICS 日历目录还需要显式文件系统授权（或 Flatseal 中的等效项）。

:::

分发包安装：

- `dcal` 至 `/usr/bin/dcal`（Quickshell UI 嵌入在二进制文件中）
- 桌面入口、图标、shell 补全以及 `/usr/lib/systemd/user/` 下的 `dcal.service`

### 从源代码构建 {#from-source}

Quickshell UI 在构建时嵌入到 `dcal` 二进制文件中，其中一部分位于 [dank-qml-common](https://github.com/AvengeMedia/dank-qml-common) 子模块中 - 使用 `--recurse-submodules` 进行克隆（或在现有克隆中运行 `git submodule update --init`）：

```bash
git clone --recurse-submodules https://github.com/AvengeMedia/dankcalendar
cd dankcalendar
make
sudo make install
```

这将安装：

- `dcal` 二进制到 `/usr/local/bin`（UI 嵌入）
- 桌面入口+图标

使用 `PREFIX=/usr sudo make install` 覆盖前缀。

## 登录时运行 {#running-at-login}

DankCalendar 作为后台守护进程运行，窗口只是它的一个视图。要保持其跨登录运行，请选择以下选项之一：

### systemd 用户服务 {#systemd-user-service}

分发包和`make install-systemd`都提供了一个用户单元。从分发包安装或从源代码构建后：

```bash
systemctl --user enable --now dcal
```

在没有 systemd 安装目标的情况下从源代码构建时：

```bash
make install-systemd
systemctl --user enable --now dcal
```

### 登录时启动（XDG 自动启动） {#start-at-login-xdg-autostart}

从 **设置 → 常规** 切换 **登录时开始**。这管理启动 `dcal run -d --hidden` 的 XDG 自动启动条目，因此守护进程会隐藏起来并在托盘中等待。
