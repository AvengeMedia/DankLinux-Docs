# 进程间通信 {#ipc}

dcal 守护进程公开了一个可编写脚本的 IPC 界面，方便合成器按键绑定和自动化。调用方法并以 `key=value` 对形式传递参数：

```bash
dcal ipc ui.toggle
dcal ipc events.list from=2026-06-01T00:00:00Z to=2026-06-30T23:59:59Z
dcal ipc reminders.upcoming limit=5
```

列出每个可用的方法及其参数：

```bash
dcal ipc list
```

结果以 JSON 形式打印，因此它们可以干净地通过管道传输到 `jq` 和朋友中。

## 常用方法 {#common-methods}

### 用户界面 {#ui}

|方法|描述 |
| -------------- | ----------------------------------------------------------------- |
| `ui.show` |显示日历窗口 — `view` (`month\|week\|day\|agenda`) |
| `ui.hide` |隐藏日历窗口 |
| `ui.toggle` |切换日历窗口 — `view` (`month\|week\|day\|agenda`) |
| `ui.open` |打开 `webcal://` 或 https ICS 订阅链接 — `url*` |
| `ui.openEvent` |打开特定事件的详细信息窗口 — `uid*`、`start` (RFC3339) |
| `ui.quit` |退出正在运行的守护进程 |

`ui.openEvent` 通过 iCal UID 来寻址事件（`events.list` 将其包含为 `uid`），因此栏小部件等外部工具可以直接跳转到事件的本机详细信息视图。重复出现的事件共享系列 UID；传递事件的 `start` 来固定特定实例：

```bash
dcal ipc ui.openEvent uid=abc123@google.com
dcal ipc ui.openEvent uid=weekly-standup@example.com start=2026-07-06T09:00:00Z
```

如果日历窗口尚未打开，它将在加载后启动并导航。

### 活动 {#events}

|方法|参数|
| --------------- | ------------------------------------------------------------------------- |
| `events.list` | `query`、`from` (RFC3339)、`to` (RFC3339)、`limit`、`offset`（全部可选）|
| `events.get` | `uid*`、`calendarId`、`start`（重复事件的发生开始 RFC3339）|
| `events.create` | `calendarId*`、`summary*`、`start*`、`end*`、`description`、`location`、`allDay`、`status` (`confirmed\|tentative\|cancelled`)、`reminders`、`recurrence`（RRULE 列表）|
| `events.update` | `id*`，加上任何创建字段，加上 `occurrenceStart`（RFC3339 — 移动重复序列的单个出现）|
| `events.delete` | `id*` |
| `events.rsvp` | `id*`、`response*` (`accept\|decline\|tentative`) — 回复会议邀请 |

### 任务 {#tasks}

|方法|参数|
| ---------------- | -------------------------------------------------------------------------- |
| `tasks.list` | `query`、`calendarId`、`includeCompleted`（`true\|false`，默认 true）、`limit`、`offset`（全部可选）|
| `tasks.get` | `id*` |
| `tasks.create` | `calendarId*`、`summary*`、`description`、`location`、`due`（RFC3339）、`start`（RFC3339）、`allDay`、 `priority` (`0-9`)、`status` (`needs_action\|in_process\|completed\|cancelled`)、`parentUid`、`reminders`、`recurrence` |
| `tasks.update` | `id*`，加上任何创建字段，加上 `percentComplete` (`0-100`) |
| `tasks.complete` | `id*`、`completed`（`true\|false`，默认 true）|
| `tasks.delete` | `id*` |

### 日历 {#calendars}

|方法|参数|
| ---------------------- | ------------------------------------------------------------- |
| `calendars.list` | — |
| `calendars.create` | `accountId*`、`name*`（在本地账户中创建日历）|
| `calendars.setHidden` | `calendarId*`、`hidden*`（`true\|false`） |
| `calendars.rename` | `calendarId*`、`name`（空清除倍率）|
| `calendars.setReminders`| `calendarId*`、`overrides`（省略继承全局设置）|
| `calendars.delete` | `calendarId*` |

### 账户 {#accounts}

|方法|参数|
| ------------------ | ------------------------------- |
| `accounts.list` | — |
| `accounts.refresh` | `accountId`（全部为空同步）|

### 提醒 {#reminders}

|方法|参数|
| -------------------- | --------------------- |
| `reminders.upcoming` | `limit`（默认20）|
| `reminders.test` |触发测试通知 |

### 系统 {#system}

|方法|参数|
| ----------------------- | ------------------------------------------------------------- |
| `system.autostart.get` |报告自动启动状态 |
| `system.autostart.set` | `enabled*` (`true\|false`) |
| `system.colorScheme.get`|当前门户配色方案（`0` 无偏好、`1` 深色、`2` 浅色）|
| `system.openUri` | `uri*` — 使用桌面门户的默认处理程序打开 URI |

### 实时更新 {#live-updates}

订阅推送事件而不是轮询。对于反映日历状态的栏小部件来说很方便：

|方法|参数|
| ------------- | ------------------------------------------------------------- |
| `subscribe` | `topics` — `accounts,calendars,events,tasks,sync,ui` 的逗号列表（如果省略则全部）|
| `unsubscribe` | `topics` — 停止接收的主题 |
| `ping` |活性检查 |
| `version` |守护进程和 API 版本 |
| `describe` |列出每个方法及其参数（与 `ipc list` 相同的数据）|

:::tip
`*` 标记必需参数。在您安装的版本上运行 `dcal ipc list` 以获得完整的、始终最新的方法集。
:::

## 按键绑定示例 {#keybind-example}

在合成器中绑定一个键来切换日历。对于尼里：

```kdl
binds {
    Mod+Shift+C { spawn "dcal" "ipc" "ui.toggle"; }
}
```
