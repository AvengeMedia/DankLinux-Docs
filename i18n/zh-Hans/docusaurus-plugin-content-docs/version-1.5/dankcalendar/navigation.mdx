# 键盘和导航 {#keyboard--navigation}

日历窗口完全由键盘驱动。随时按 <kbd>?</kbd> 即可调出应用内快捷方式叠加层。

## 浏览次数 {#views}

有五个视图可用。从侧边栏或使用下面的键在它们之间切换。

|查看 |描述 |
| ---------- | -------------------------------------------------------- |
| **月** |全月网格（默认视图）|
| **周** |七日时间网格 |
| **日** |单日时间网格 |
| **议程** |未来几天的滚动列表 |
| **任务** |您的 VTODO 任务列表 — 在启用“显示任务”并且账户提供这些任务时显示 |

您上次使用的视图会在各个会话中被记住。您还可以从 CLI 打开特定视图，例如`dcal show --view week`。

## 四处走动 {#moving-around}

- <kbd>t</kbd> 跳回**今天**。
- <kbd>h</kbd>/<kbd>l</kbd>（或<kbd>←</kbd>/<kbd>→</kbd>）移动一一次**天**。
- <kbd>[</kbd>/<kbd>]</kbd>（或<kbd>PgUp</kbd>/<kbd>PgDn</kbd>) 移动一个**周期** — 一天、一周或一个月，具体取决于当前视图。
- <kbd>&#123;</kbd>/<kbd>&#125;</kbd> 向后或向前跳跃整整**年**。
- <kbd>g</kbd> 打开**转到日期**对话框以进行更大的跳转。

### 转到日期 {#go-to-date}

按 <kbd>g</kbd> 打开一个紧凑的跳转对话框，用于一步跨越长距离。您可以：

- **输入日期**并按 <kbd>Enter</kbd>。可以理解多种格式，包括 `2026-07-13` (ISO)、`2026/07/13`、`2026.07.13`、`2026-07`（月初）和 `2026`（年初）。许多书面形式（例如 `Jul 13 2026`）也适用。当您键入识别的日期时，选择器会对其进行预览。
- **使用迷你选择器。** 单 V 形逐月，双 V 形逐年；单击某一天可直接跳转到该日期。

## 选择并开启活动 {#selecting-and-opening-events}

在日、周和议程视图中，<kbd>j</kbd>/<kbd>k</kbd>（或<kbd>↓</kbd>/<kbd>↑</kbd>) 按时间顺序浏览事件，穿越到发生事件的下一天或前一天。在月视图中，相同的键按周移动。

- <kbd>Tab</kbd>/<kbd>Shift+Tab</kbd> 跳转到下一个或上一个有事件的**日。
- <kbd>Enter</kbd> 打开所选事件，如果未选择任何内容，则创建一个新事件。
- <kbd>Esc</kbd> 清除当前事件选择。
- <kbd>c</kbd> 在所选日期创建事件。

## 搜索 {#search}

按 <kbd>/</kbd> 或 <kbd>Ctrl+F</kbd> 打开聚光灯式搜索。输入至少两个字符以在每个连接的日历中进行搜索；选择结果会跳转到并打开该事件。

## 快捷方式参考 {#shortcut-reference}

### 导航 {#navigation}

|按键|行动|
| ---- | ------ |
| <kbd>t</kbd> |转到今天|
| <kbd>h</kbd> / <kbd>←</kbd> |前一天 |
| <kbd>l</kbd> / <kbd>→</kbd> |第二天 |
| <kbd>j</kbd> / <kbd>↓</kbd> |下一个活动（月视图中的下周）|
| <kbd>k</kbd> / <kbd>↑</kbd> |上一个活动（月视图中的前一周）|
| <kbd>[</kbd> / <kbd>PgUp</kbd> |前一天、前一周或前一个月 |
| <kbd>]</kbd> / <kbd>PgDn</kbd> |下一天、下周或下个月 |
| <kbd>&#123;</kbd> |上一年 |
| <kbd>&#125;</kbd> |明年 |
| <kbd>g</kbd> | 转到日期 |
| <kbd>Tab</kbd> |第二天有活动 |
| <kbd>Shift+Tab</kbd> |活动前一天 |
| <kbd>Enter</kbd> |打开或创建活动 |
| <kbd>Esc</kbd> |清除事件选择 |

### 观看次数 {#views-1}

|按键|行动|
| ---- | ------ |
| <kbd>d</kbd> / <kbd>Ctrl+1</kbd> |日景|
| <kbd>w</kbd> / <kbd>Ctrl+2</kbd> |周视图 |
| <kbd>m</kbd> / <kbd>Ctrl+3</kbd> |月视图 |
| <kbd>a</kbd> / <kbd>Ctrl+4</kbd> |议程视图 |
| <kbd>Ctrl+5</kbd> |任务视图 |

### 侧边栏 {#sidebar}

按 <kbd>s</kbd> 聚焦侧边栏；按 <kbd>s</kbd> 或 <kbd>Esc</kbd> 离开它。

|按键|行动|
| ---- | ------ |
| <kbd>j</kbd> / <kbd>k</kbd> |浏览侧边栏项目 |
| <kbd>h</kbd> / <kbd>l</kbd> |折叠或展开部分 |
| <kbd>Enter</kbd> / <kbd>Space</kbd> |切换日历、切换视图或同步账户 |
| <kbd>r</kbd> |重命名日历 |
| <kbd>Del</kbd> |删除日历或账户 |

### 一般 {#general}

|按键|行动|
| ---- | ------ |
| <kbd>c</kbd> |创建活动 |
| <kbd>/</kbd> / <kbd>Ctrl+F</kbd> |搜索 |
| <kbd>Ctrl+,</kbd> |设置 |
| <kbd>?</kbd> |切换快捷方式叠加 |

:::note
在从右到左的区域设置下，日历会自动镜像，水平导航键 (<kbd>h</kbd>/<kbd>l</kbd>、 <kbd>←</kbd>/<kbd>→</kbd>）遵循镜像方向。
:::
