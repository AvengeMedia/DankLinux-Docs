# DankCalendar {#dankcalendar}

DankCalendar 是一款适用于 Linux 和 FreeBSD 的免费开源桌面日历应用程序。其目的是将您的本地日历、[Google](https://calendar.google.com/)、[Microsoft](https://outlook.com/)、[CalDAV](https://en.wikipedia.org/wiki/CalDAV) 和 [iCloud](https://www.icloud.com/calendar/) 日历集中在一处，以便您可以查看和管理活动、回复会议邀请、跟踪任务以及获取提醒您的所有账户 - 而您的数据保留在您的设备上。它作为带有托盘图标的轻量级守护程序运行，使您的账户在后台保持同步，并具有 [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell) 的外观和感觉。 `dcal` 是 DankCalendar 的命令行名称。

使用 [Quickshell](https://quickshell.org/) 和 [Go](https://go.dev/) 构建。

## 特点 {#features}

- **多个提供商**：连接本地、Google、Microsoft、CalDAV、iCloud、Evolution 和只读 iCal/webcal 订阅，并在单个统一议程中查看每个日历。
- **月、周、日、议程和任务**：在五个视图之间切换，支持重复事件和完整的重复编辑。
- **任务**：从提供任务列表的日历中查看、创建和完成 VTODO 任务。
- **会议邀请**：接受、拒绝或暂时回复邀请，并将与会者状态推送回您的提供商。
- **后台同步**：轻量级守护进程使您的账户保持同步并通过 IPC 提供 UI。关闭窗口只会隐藏它。同步和提醒继续运行。
- **事件提醒**：即将发生的事件的本机桌面通知，具有每个事件和每个日历提醒配置。
- **托盘集成**：用于显示、隐藏和退出应用程序的系统托盘图标，以及快速访问即将发生的事件。
- **安全凭证**：OAuth 令牌和账户机密存储在您的系统密钥环中，而不是存储在纯文本配置文件中。
- **键盘导航**：完全键盘驱动的导航，具有快捷方式覆盖、最新跳转以及跨事件的聚光灯式搜索。
- **可编写脚本的 IPC**：用于按键绑定和自动化的可编写脚本的 IPC 界面。
- **本地化**：面向用户的字符串可通过 POEditor 进行翻译和管理，并具有自动从右到左的布局镜像。
