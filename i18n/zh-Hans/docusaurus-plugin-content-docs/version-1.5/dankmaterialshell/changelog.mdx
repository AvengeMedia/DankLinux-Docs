## v1.5.3 {#v153}

### 特点 {#features}
- DankCalendar 已作为 Flatpak 在 [Flathub](https://flathub.org/apps/com.danklinux.dankcalendar) 上发布！

```bash
flatpak install flathub com.danklinux.dankcalendar
flatpak run com.danklinux.dankcalendar
```
