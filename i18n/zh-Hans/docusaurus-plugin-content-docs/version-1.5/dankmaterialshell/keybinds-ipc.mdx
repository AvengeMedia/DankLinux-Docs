DankMaterialShell 提供全面的 IPC（进程间通信）功能，允许通过命令行命令对 shell 进行外部控制。所有 IPC 命令都遵循以下格式：

```bash
dms ipc call <target> <function> [parameters...]
```

## 发现IPC命令 {#discovering-ipc-commands}

列出 DMS 运行时所有可用的目标和函数：

```bash
dms ipc list     # list all targets and functions
dms ipc          # same
dms ipc --help   # same, plus usage text
```

:::note
实时列表需要 DMS 运行。如果列出失败，请使用此页面作为离线参考或使用 `dms run` 启动 shell。
:::

## 核心控制 {#core-controls}

### 音频 {#audio}

管理音频输出和输入设备。

|功能|描述 |参数|
| --- | --- | --- |
| `setvolume <percentage>` |设置输出音量 |百分比 (0-100) |
| `increment <step>` |增加输出音量 |步骤（默认：5）|
| `decrement <step>` |降低输出音量 |步骤（默认：5）|
| `mute` |切换输出静音 | - |
| `setmic <percentage>` |设置麦克风音量 |百分比 (0-100) |
| `micmute` |切换麦克风静音 | - |
| `cycleoutput` |循环切换音频输出设备 | - |
| `status` |获取当前音频状态 | - |

**示例：**
```bash
dms ipc call audio setvolume 50
dms ipc call audio increment 10
dms ipc call audio mute
dms ipc call audio cycleoutput
```

:::note
`audio setmic` 和 `audio micmute` 仍可用于向后兼容，但新脚本和按键绑定应使用下面的专用 [`mic`](#mic) 目标。
:::

### 麦克风 {#mic}

具有交互式 OSD 支持的专用麦克风输入控制。

|功能|描述 |参数|
| --- | --- | --- |
| `setvolume <percentage>` |设置麦克风音量 |百分比 (0-100) |
| `increment <step>` |增加麦克风音量（如果静音则取消静音）|步骤（默认：5）|
| `decrement <step>` |降低麦克风音量（如果静音则取消静音）|步骤（默认：5）|
| `mute` |切换麦克风静音 | - |
| `status` |获取当前麦克风音量和静音状态 | - |

**示例：**
```bash
dms ipc call mic setvolume 75
dms ipc call mic increment 5
dms ipc call mic decrement 10
dms ipc call mic mute
dms ipc call mic status
```

**注释：**
- 调整麦克风音量会触发交互式 OSD（当 `osdMicVolumeEnabled` 开启时），带有可拖动滑块和静音开关，镜像扬声器音量 OSD。
- `increment` 和 `decrement` 在更改级别之前自动取消麦克风静音。

### 亮度 {#brightness}

控制内部和外部显示器的显示亮度。

|功能|描述 |参数|
| --- | --- | --- |
| `set <percentage> [device]` |设置亮度级别 |百分比（1-100），设备（可选）|
| `increment <step> [device]` |增加亮度|步骤、设备（可选）|
| `decrement <step> [device]` |降低亮度 |步骤、设备（可选）|
| `status` |获取当前亮度状态 | - |
| `list` |列出所有亮度设备 | - |
| `enableExponential [device]` |启用指数亮度模式 |设备（可选，如果未指定则使用电流）|
| `disableExponential [device]` |禁用指数亮度模式 |设备（可选，如果未指定则使用电流）|
| `toggleExponential [device]` |切换指数亮度模式 |设备（可选，如果未指定则使用电流）|

**示例：**
```bash
dms ipc call brightness set 80
dms ipc call brightness increment 10 ""
dms ipc call brightness decrement 5 "intel_backlight"
dms ipc call brightness disableExponential "backlight:intel_backlight"
dms ipc call brightness toggleExponential
```

### 晚上 {#night}

夜间模式（伽玛/色温）控制。

|功能|描述 |参数|
| --- | --- | --- |
| `toggle` |打开/关闭夜间模式| - |
| `enable` |启用夜间模式 | - |
| `disable` |禁用夜间模式 | - |
| `status` |获取夜间模式状态 | - |
| `getCurrentTemp` |获取实时伽马温度 | - |
| `getTargetTemp` |获取配置的夜间温度 | - |
| `getDayTemp` |获取配置的日间温度 | - |
| `setTargetTemp <value>` |设置夜间温度 |开尔文值 (2500-6000) |
| `setDayTemp <value>` |设置日间温度（自动化开启时适用）|开尔文值 (2500-6000) |
| `getSchedule` |获取自动化详细信息（模式、周期、日照时间、下一次转换）| - |
| `automation [mode]` |获取/设置自动化模式 | “手动”、“时间”或“位置”（可选）|
| `schedule <start> <end>` |设置基于时间的时间表 |开始时间 (HH:MM)、结束时间 (HH:MM) |
| `location <lat> <lon>` |设置位置坐标|纬度、经度 |

**示例：**
```bash
dms ipc call night toggle
dms ipc call night getCurrentTemp
dms ipc call night setTargetTemp 4000
dms ipc call night setDayTemp 5500
dms ipc call night getSchedule
dms ipc call night automation time
dms ipc call night schedule 20:00 06:00
dms ipc call night location 40.7128 -74.0060
```

### 锁 {#lock}

屏幕锁定控制和状态。

|功能|描述 |
| --- | --- |

| `lockAndOutputsOff` |锁定屏幕，淡入黑色，然后关闭显示器电源（GNOME Super+L 风格）。任何输入都会取消淡入淡出或唤醒显示器；淡入淡出持续时间遵循淡入淡出至 DPMS 宽限期设置。 |

### 会议 {#sessions}

在当前席位上已运行的登录会话之间切换。包裹 `loginctl list-sessions` 和 `loginctl activate`。

|功能|描述 |参数|
| --- | --- | --- |
| `list` |将会话列为制表符分隔行（当前标记为 `*current*`）| - |
| `refresh` |在后台重新枚举会话 | - |
| `open` |刷新并打开“切换用户”选择器 | - |
| `activate <sessionId>` |通过数字登录 ID 激活会话 |会话 ID |
| `switchTo <target>` |通过用户名或会话 ID 激活会话 |目标（用户名或会话 ID）|

**示例：**
```bash
# See what's switchable
dms ipc call sessions list

# Open the Switch User picker (good for a keybind)
dms ipc call sessions open

# Jump straight to another logged-in user
dms ipc call sessions switchTo testuser2

# Or by session ID
dms ipc call sessions activate 4
```

:::note
这仅在当前席位上“已存在”的会话之间切换。为未登录的用户创建全新会话需要多会话欢迎器（greetd-flexiserver / GDM / LightDM）；选择器的空状态提供了注销回退以联系迎宾员。
:::

当没有目标匹配时，`dms switch-user [target]` CLI 命令会使用更友好的交互列表包装相同的调用。

|功能|描述 |

| `enable` |启用空闲抑制（防止睡眠）|
| `disable` |禁用空闲抑制（允许睡眠）|

**示例：**

### 电源配置文件 {#powerprofile}

通过 PowerProfiles D-Bus 接口进行电源配置控制。更改与 DMS UI 保持同步，并在“设置”→“OSD”中启用时触发电源配置文件 OSD。

需要安装并运行 `power-profiles-daemon` 或 `tuned` 和 `tuned-ppd`。适用于所有合成器。

|功能|描述 |参数|
| --- | --- | --- |
| `open` |显示电源配置文件选择器模式 | - |
| `close` |关闭电源配置文件选择器模式 | - |
| `toggle` |切换电源配置文件选择器模态可见性 | - |
| `list` |列出可用的配置文件段（每行一个）| - |
| `status` |获取当前活动的配置文件 slug | - |
| `set <profile>` |设置有功功率配置文件 | slug 或别名（见下文）|
| `cycle` |循环到下一个可用的配置文件 | - |

**`set` 的配置文件段和别名：**
- `power-saver` — 还有 `powersaver`、`saver`、`0`
- `balanced` — 也 `1`
- `performance` — 以及 `2`（仅当硬件支持时）

**循环顺序：** `power-saver` → `balanced` → `performance` → `power-saver`（跳过您的硬件上不可用的配置文件）。

**示例：**
```bash
dms ipc call powerprofile status
dms ipc call powerprofile list
dms ipc call powerprofile cycle
dms ipc call powerprofile set balanced
dms ipc call powerprofile set performance
dms ipc call powerprofile toggle
```

**注释：**
- `list` 仅返回系统上可用的配置文件（不支持时忽略性能）
- `status` 返回当前的段：`power-saver`、`balanced` 或 `performance`
- 当没有 PowerProfiles 守护程序（`power-profiles-daemon` 或 `tuned-ppd`）运行时，返回 `ERROR: power-profiles-daemon not available`
- 如果无法应用配置文件更改，则返回 `ERROR: Failed to set power profile`

## 壁纸和个人资料 {#wallpaper--profile}

### 壁纸 {#wallpaper}

壁纸管理支持全局和每显示器配置。

#### 全局壁纸功能 {#global-wallpaper-functions}

|功能|描述 |参数|
| --- | --- | --- |
| `get` |获取当前壁纸路径| - |
| `set <path>` |设置壁纸|图像文件路径 |
| `clear` |清除所有壁纸 | - |
| `next` |循环到下一张壁纸| - |
| `prev` |循环到上一张壁纸 | - |

#### 每个监视器的功能 {#per-monitor-functions}

|功能|描述 |参数|
| --- | --- | --- |
| `getFor <screen>` |获取显示器壁纸 |显示器名称（例如“DP-2”）|
| `setFor <screen> <path>` |设置显示器壁纸|显示器名称、图像路径 |
| `nextFor <screen>` |循环到下一张壁纸|显示器名称 |
| `prevFor <screen>` |循环到上一张壁纸|显示器名称 |

**示例：**
```bash
# Global wallpaper mode
dms ipc call wallpaper set /path/to/image.jpg
dms ipc call wallpaper next

# Per-monitor wallpaper mode
dms ipc call wallpaper setFor DP-2 /path/to/image1.jpg
dms ipc call wallpaper setFor eDP-1 /path/to/image2.jpg
dms ipc call wallpaper nextFor eDP-1

# Clear and return to global mode
dms ipc call wallpaper clear
```

**注意：** 启用每监视器模式时，旧版全局函数将返回错误消息，指导您使用每监视器等效项。

### 酒吧 {#bar}

使用灵活的选择器控制各个条。

|功能|描述 |参数|
| --- | --- | --- |
| `reveal <selector> <value>` |显示酒吧 |选择器 + 值 |
| `hide <selector> <value>` |隐藏酒吧 |选择器 + 值 |
| `toggle <selector> <value>` |切换栏可见性 |选择器 + 值 |
| `status <selector> <value>` |获取酒吧可见性状态 |选择器 + 值 |
| `autoHide <selector> <value>` |启用自动隐藏模式 |选择器 + 值 |
| `manualHide <selector> <value>` |禁用自动隐藏模式 |选择器 + 值 |
| `toggleAutoHide <selector> <value>` |切换自动隐藏模式 |选择器 + 值 |
| `toggleReveal <selector> <value>` |切换自动隐藏栏的运行时显示/隐藏状态 |选择器 + 值 |
| `getPosition <selector> <value>` |获取酒吧位置 |选择器 + 值 |
| `setPosition <selector> <value> <position>` |设置栏位置|选择器 + 值 + 位置（上、下、左、右）|

**注意：** `toggleReveal` 仅影响启用了自动隐藏的栏。将指针移动到栏显示区域会清除 IPC 显示状态，并且手控将恢复到正常的悬停自动隐藏行为。

**选择器：**
- `index` - 按位置选择（从 0 开始）
- `id` - 通过唯一的条 ID 选择
- `name` - 按酒吧名称选择

**示例：**
```bash
# By index
dms ipc call bar hide index 0
dms ipc call bar reveal index 1
dms ipc call bar toggle index 0

# By name
dms ipc call bar toggle name "Main Bar"
dms ipc call bar status name "Secondary"

# By ID
dms ipc call bar reveal id abc123

# Auto-hide controls
dms ipc call bar autoHide index 0
dms ipc call bar manualHide name "Main Bar"
dms ipc call bar toggleAutoHide index 1
dms ipc call bar toggleReveal index 0

# Position controls
dms ipc call bar getPosition index 0
dms ipc call bar getPosition id default
dms ipc call bar setPosition index 0 top
dms ipc call bar setPosition id default left
```

### 小部件 {#widget}

控制栏小部件弹出窗口、菜单和可见性（包括插件）。

|功能|描述 |参数|
| --- | --- | --- |
| `toggle <widgetId>` |切换小部件弹出窗口可见性 |小部件 ID |
| `openWith <widgetId> <mode>` |以特定模式打开小部件弹出窗口 |小部件 ID、模式 |
| `toggleWith <widgetId> <mode>` |在特定模式下切换小部件弹出窗口 |小部件 ID、模式 |
| `openQuery <widgetId> <query>` |使用预填充的搜索查询打开小部件弹出窗口 |小部件 ID、查询文本 |
| `toggleQuery <widgetId> <query>` |使用预填充的搜索查询切换小部件弹出窗口 |小部件 ID、查询文本 |
| `list` |列出所有已注册的具有可见性状态的小部件 ID | - |
| `status <widgetId>` |获取小部件弹出窗口可见性状态 |小部件 ID |
| `visibility <widgetId>` |获取小部件可见性状态 |小部件 ID |
| `reveal <widgetId>` |强制小部件可见 |小部件 ID |
| `hide <widgetId>` |强制隐藏小部件 |小部件 ID |
| `reset <widgetId>` |清除可见性覆盖，恢复正常行为 |小部件 ID |

**示例：**
```bash
dms ipc call widget list
dms ipc call widget toggle clock
dms ipc call widget status weather

# Open widget popout in a specific mode (e.g., launcher tabs)
dms ipc call widget openWith launcherButton all
dms ipc call widget openWith launcherButton files
dms ipc call widget openWith launcherButton apps
dms ipc call widget openWith launcherButton plugins
dms ipc call widget toggleWith launcherButton files

# Open widget popout with a pre-filled search query
dms ipc call widget openQuery launcherButton "browser"
dms ipc call widget toggleQuery launcherButton "settings"

# Control widget visibility on the bar
dms ipc call widget visibility weather
dms ipc call widget hide weather
dms ipc call widget reveal weather
dms ipc call widget reset weather
```

**注释：**
- 使用 `list` 发现可用的小部件 ID 及其当前可见性状态（`[visible]` 或 `[hidden]`）
- 小部件 ID 取决于您的栏设置中启用了哪些小部件
- `status` 函数返回小部件 **弹出** 状态的“可见”或“隐藏”
- `visibility`、`reveal`、`hide` 和 `reset` 函数控制小部件的**栏存在**（无论它是否出现在栏上）
- 插件可以通过 `visibilityCommand` 定义条件可见性 — 使用 `reset` 在覆盖后返回到该行为

## 模态控件 {#modal-controls}

这些目标控制各种模式窗口和叠加层。

### 聚光灯 {#spotlight}

具有搜索功能的应用程序启动器模式。

:::note
`spotlight` 和 `launcher` 是同义词 - 两个目标都调用相同的启动器模式以实现向后兼容性。
:::

|功能|描述 |参数|

| `toggleQuery <query>` |切换启动器与搜索 |搜索文本|

**示例：**
```bash
dms ipc call spotlight toggle

dms ipc call spotlight openWith apps
dms ipc call spotlight toggleWith files
```

|功能|描述 |参数|

| `openQuery <query>` |显示带有搜索的聚光灯栏 |搜索文本|
| `toggleQuery <query>` |通过搜索切换聚光灯栏 |搜索文本|

**示例：**
```bash
dms ipc call spotlight-bar toggle

dms ipc call spotlight-bar close

dms ipc call spotlight-bar toggleQuery "!"
dms ipc call spotlight-bar openWith apps

```

### 其他情态动词 {#other-modals}

所有这些模态都支持 `open`、`close` 和 `toggle` 功能：

- **剪贴板** - 剪贴板历史记录管理器
- **通知** - 通知中心（还支持 `clearAll`、`dismissAllPopups`、`toggleDoNotDisturb`、`getDoNotDisturb`、`enableDoNotDisturbIndefinitely`、`enableDoNotDisturbUntilTomorrowMorning` 和 `enableDoNotDisturbUntil <timestampMs>`）
- **进程列表** - 系统进程列表和性能监视器（还支持`focusOrToggle`）
- **powermenu** - 用于系统操作的电源菜单
- **控制中心** - 快速设置（网络、蓝牙、音频等）
- **记事本** - 快速记事本/便签本

**示例：**
```bash

dms ipc call notifications open
dms ipc call notifications clearAll
dms ipc call notifications dismissAllPopups
dms ipc call notifications toggleDoNotDisturb
dms ipc call notifications getDoNotDisturb
dms ipc call notifications enableDoNotDisturbIndefinitely
dms ipc call notifications enableDoNotDisturbUntilTomorrowMorning
dms ipc call notifications enableDoNotDisturbUntil 1744819200000
dms ipc call processlist open
dms ipc call powermenu toggle
dms ipc call control-center toggle

```

### 吐司 {#toast}

显示用户反馈的 Toast 通知和脚本警报。

|功能|描述 |参数|
| --- | --- | --- |
| `info <message>` |显示信息吐司（1.5 秒）|留言内容|
| `infoWith <message> <details> <command> <category>` |信息吐司与额外的|消息、详细信息、命令、类别 |
| `warn <message>` |显示警告 Toast（3 秒）|留言内容|
| `warnWith <message> <details> <command> <category>` |警告吐司与额外的|消息、详细信息、命令、类别 |
| `error <message>` |显示错误 toast（5 秒）|留言内容|
| `errorWith <message> <details> <command> <category>` |带有额外内容的错误吐司（8s，可扩展）|消息、详细信息、命令、类别 |
| `hide` |隐藏当前的吐司 | - |
| `dismiss <category>` |按类别关闭祝酒 |类别名称 |
| `status` |获取当前的 toast 状态 | - |

**示例：**
```bash
# Simple messages
dms ipc call toast info "Build complete"
dms ipc call toast warn "Disk space low"
dms ipc call toast error "Connection failed"

# With details (expandable in UI)
dms ipc call toast errorWith "Git push failed" "Permission denied (publickey)" "git push origin main" "git"

# With category for later dismissal
dms ipc call toast warnWith "Downloading update..." "" "" "updater"
dms ipc call toast dismiss "updater"

# Check current state
dms ipc call toast status

# Force hide
dms ipc call toast hide
```

**注释：**
- `*With` 变体接受可选详细信息（可在 UI 中扩展）、命令字符串和类别
- 使用空字符串 (`""`) 作为要跳过的可选参数
- 类别允许对相关的 toast 进行分组以便批量解雇
- `status` 函数返回 `hidden` 或 `visible:level:message`

## 脚本和自动化 {#scripting-and-automation}

IPC 命令设计用于与键绑定、脚本和自动化工具集成。

### 基于时间的自动化 {#time-based-automation}

```bash
#!/bin/bash
# Toggle night mode based on time of day
hour=$(date +%H)
if [ $hour -ge 20 ] || [ $hour -le 6 ]; then
    dms ipc call night enable
else
    dms ipc call night disable
fi
```

### 状态检查 {#status-checking}

```bash
# Check if screen is locked before performing action
if dms ipc call lock isLocked | grep -q "false"; then
    dms ipc call notifications open
fi
```

### 条件逻辑 {#conditional-logic}

```bash
# Increase brightness only if below threshold
current=$(dms ipc call brightness status | grep -oP '\d+')
if [ "$current" -lt 50 ]; then
    dms ipc call brightness set 50
fi

# Cycle power profile only when not in performance mode
if [ "$(dms ipc call powerprofile status)" != "performance" ]; then
    dms ipc call powerprofile cycle
fi
```

## 返回值 {#return-values}

大多数 IPC 函数返回字符串消息，指示：
- 使用当前值成功确认
- 如果操作失败，会出现错误消息
- 查询功能的状态信息
- 简单操作函数的空/无效返回

返回 void 的函数（如媒体控件）执行操作但不提供反馈。如果需要，可以通过其他方式检查应用程序状态。
