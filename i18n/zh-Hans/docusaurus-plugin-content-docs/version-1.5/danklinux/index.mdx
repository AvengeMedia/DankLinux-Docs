## 概述 {#overview}

**DankLinux 存储库** 为 **DankMaterialShell** 和 **niri** 提供预构建的软件包！ \
DankMaterialShell 现在可用于比以往更多的发行版！

- [**Fedora**](https://fedoraproject.org/) | [**CentOS**](https://www.centos.org/) | [**OpenSUSE**](https://www.opensuse.org/)
- [**Debian**](https://www.debian.org/) | [**Ubuntu**](https://ubuntu.com/) | [**无效Linux**](https://voidlinux.org/)

### 桌面环境 {#desktop-environment}
- **DankMaterialShell (dms)**：带有小部件和 CLI 工具的完整桌面 shell
- **DankMaterialShell (dms-git)**：具有最新功能的开发版本

### 合成器 {#compositors}
- [**Niri**](https://github.com/niri-wm/niri)：可滚动平铺 Wayland 合成器
- [**Niri-git**](https://github.com/niri-wm/niri)：niri 的开发版本

### 核心框架 {#core-framework}
- [**Quickshell**](https://github.com/quickshell-mirror/quickshell)：基于 QtQuick 的 Wayland 桌面 shell 框架 — 在 **Debian** 上，使用本机包（见下文）； DankLinux 版本仍适用于其他发行版
- [**Quickshell-git**](https://github.com/quickshell-mirror/quickshell)：Quickshell 的开发版本（DankLinux 存储库）

### 实用程序 {#utilities}
- [**cliphist**](https://github.com/sentriz/cliphist)：具有历史记录支持的 Wayland 剪贴板管理器
- [**dgop**](https://github.com/AvengeMedia/dgop)：Avenge Media 的无状态 CPU/GPU 监控系统
- [**dsearch**](https://github.com/AvengeMedia/danksearch)：Avenge Media 提供的速度极快的文件系统搜索工具
- [**DankCalendar**](https://github.com/AvengeMedia/dankcalendar) (`dcal`)：适用于 Local、Google、Microsoft、CalDAV 和 iCloud 的独立日历应用程序 — 包 **`dankcalendar-git`**
- [**matugen**](https://github.com/InioX/matugen)：Material Design 3 主题调色板生成器
- [**xWayland-Satellite**](https://github.com/Supreeeme/xwayland-satellite)：XWayland 集成工具
- [**xWayland-Satellite-git**](https://github.com/Supreeeme/xwayland-satellite)：xWayland-Satellite 的开发版本

- **Ubuntu/Debian**：请参阅安装指南中的 [Ubuntu 和 Debian](../dankmaterialshell/installation#debian--ubuntu) 部分
- **OpenSUSE**：请参阅安装指南中的 [OpenSUSE](../dankmaterialshell/installation#opensuse--derivatives) 部分

### 安装独立包 {#installing-standalone-packages}

DankLinux 存储库中的所有软件包都可以独立安装。首先，为您的发行版添加 DankLinux 存储库，然后安装您需要的软件包。

:::note

安装 **niri** 或 **niri-git** 时，**xWayland-Satellite** 会自动安装为依赖项。您不需要单独安装它。

:::

### Void Linux {#void-linux}

:::warning[存储库迁移]

如果您已经使用以前的 GitHub Pages 存储库，请将其 URL 替换为
退休前的位置：

```bash
sudo sed -i 's|https://avengemedia.github.io/DankLinux/current|https://void.danklinux.com/danklinux/current|' /etc/xbps.d/danklinux.conf
```

冻结的 GitHub Pages 存储库不再接收更新，并将被
**2026 年 7 月 24 日 22:27 UTC** 后退休。

:::

添加 DankLinux XBPS 存储库，同步它，然后安装
您需要的独立包：

```bash
echo "repository=https://void.danklinux.com/danklinux/current" | sudo tee /etc/xbps.d/danklinux.conf
sudo xbps-install -S
sudo xbps-install -S dgop danksearch dankcalendar
```

封装名称为`dgop`、`danksearch`、`dankcalendar`；他们安装
分别为 `dgop`、`dsearch` 和 `dcal` 命令。要安装 DMS 本身，
还可以在 [Void Linux DMS 安装
指南](../dankmaterialshell/installation#void-linux)。

### Niri 可滚动平铺 Wayland 合成器 {#niri-scrollable-tiling-wayland-compositor}

Niri 软件包有稳定版本和开发版本。在官方存储库中不提供 niri 的发行版上受支持。

安装 **niri** 或 **niri-git** 时，**xWayland-Satellite** 会自动安装为依赖项，提供开箱即用的 XWayland 集成。

[**维基**](https://yalter.github.io/niri/) | [**GitHub**](https://github.com/niri-wm/niri)
