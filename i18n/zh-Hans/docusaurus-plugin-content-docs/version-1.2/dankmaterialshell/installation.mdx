本指南介绍在不同 Linux 发行版和不同方式下安装 DankMaterialShell。

## 依赖项 {#dependencies}

- [**Quickshell**](https://github.com/quickshell-mirror/quickshell)（必需）- 核心框架
- [**cava**](https://github.com/karlstav/cava)（可选）- 音频可视化小部件
- [**cliphist**](https://github.com/sentriz/cliphist) + [**wl-clipboard**](https://github.com/bugaevc/wl-clipboard)（可选）- 剪贴板历史
- [**dgop**](https://github.com/AvengeMedia/dgop)（可选）- 用于资源小部件的系统遥测
- [**dsearch**](https://github.com/AvengeMedia/danksearch)（可选）- 文件系统搜索引擎
- [**matugen**](https://github.com/InioX/matugen)（可选）- Material Design 调色板生成
- [**niri**](https://github.com/niri-wm/niri)（可选）- DMS 团队选择的 Wayland 合成器
- [**qt6-multimedia**](https://github.com/qt/qtmultimedia)（可选）- 系统声音反馈

有关 Fedora、Debian、Ubuntu 和 OpenSUSE 的预构建软件包，请参阅 [DankLinux 仓库](../danklinux) 页面。

:::note

只有 **Quickshell** 是必需的。所有其他依赖项都是可选的，用于启用特定功能。

:::

## Arch 及衍生版 {#arch--derivatives}

`dms` 可在 [AUR](https://aur.archlinux.org/) 中获取，假设您已安装 aur 助手，例如 [paru](https://aur.archlinux.org/packages/paru) 或 [yay](https://aur.archlinux.org/packages/yay)。

为了保持一致，我们将在示例中使用 `paru`。

### 稳定版

```bash
paru -S dms-shell-bin
```

### 最新开发构建

```bash
paru -S dms-shell-git
```

这些软件包提供 shell、小部件和 CLI。将它们与官方仓库中的 `niri`、`hyprland`、`sway`、`mangowc` 或 `labwc` 软件包配对，即可获得完整的桌面堆栈。

## Fedora 和 CentOS {#fedora--centos}

DankMaterialShell 可通过 COPR 仓库用于 Fedora 41/42/43 rawhide 和 CentOS 10。启用团队管理的 COPR 仓库来安装预构建软件包：

### 稳定版 {#stable-release}

```bash
sudo dnf copr enable avengemedia/dms
sudo dnf install dms
```

### 最新开发构建 {#latest-development-build}

```bash
sudo dnf copr enable avengemedia/dms-git
sudo dnf install dms
```

COPR 仓库还提供配套软件包，如 `quickshell-git`、`cliphist`、`matugen` 以及默认配置使用的其他实用程序。

## 所有其他发行版 {#all-other-distributions}

:::warning

本指南不包括合成器安装。您需要一个兼容的 Wayland 合成器（niri、Hyprland、sway、dwl/MangoWC 等）。

:::

### 1. 安装必要依赖项 {#1-install-essential-dependencies}

#### Quickshell {#quickshell}

如果您的发行版不提供 quickshell 软件包，则需要从源码构建。Quickshell 需要：

**基础依赖项：**
- cmake、qt6base、qt6declarative、qtshadertools、pkg-config、cli11
- qt6declarative 的 Qt 私有头文件（Qt < 6.10 时还需要 qt6wayland）
- Qt 6.6 或更新版本

**关键功能及其依赖项：**
- **Wayland 支持**（默认启用）- qt6wayland、wayland、wayland-protocols
- **崩溃报告器**（推荐）- google-breakpad
- **Jemalloc**（推荐用于更好的内存管理）- jemalloc
- **系统托盘** - qt6dbus
- **PAM 身份验证** - pam

完整的构建说明和功能标志，请参阅 [Quickshell BUILD.md](https://git.outfoxxed.me/quickshell/quickshell/raw/branch/master/BUILD.md)。

#### AccountsService {#accountsservice}

:::note

需要 AccountsService 来持久化用户个人资料配置（如个人资料图片）。在大多数仓库中以 `accountsservice` 提供。

:::

```bash
# Arch + Friends
sudo pacman -S accountsservice
# Fedora + Friends
sudo dnf install accountsservice
# Debian, Ubuntu + Friends
sudo apt install accountsservice
# openSUSE + Friends
sudo zypper install accountsservice
# Gentoo
sudo emerge --ask sys-apps/accountsservice
```

### 2. 克隆 DMS 仓库 {#2-clone-the-dms-repository}

```bash
git clone https://github.com/AvengeMedia/DankMaterialShell.git ~/dms
```

### 3. 编译并安装 DMS 后端 {#3-compile--install-the-dms-backend}

*需要 GO 1.24+*

```bash
cd ~/dms
sudo make install
```

:::note

要卸载源码构建，请在仓库目录中运行 `sudo make uninstall`。

:::

### 4. 安装可选集成 {#4-install-optional-integrations}

使用您发行版的软件包管理器安装可选组件以获得完整功能：

- `dgop` - 详细的系统指标和进程列表
- `dsearch` - 文件系统搜索引擎
- `matugen` - Material Design 调色板生成
- `i2c-tools` - ddc 显示器背光控制
- `wl-clipboard` + `cliphist` - 剪贴板历史
- `cava` - 音频可视化小部件
- `qt6-multimedia` - 系统声音反馈

## 安装后 {#post-install}

完成安装后：

1. **生成合成器配置**（仅限 niri/Hyprland）：运行 `dms setup` 创建带有 DMS 按键绑定和自动启动的入门配置。支持其他合成器（sway、MangoWC、labwc），但需要手动配置。
2. 启用 systemd 服务（推荐）或将 `dms run` 添加到您的合成器配置中
3. 配置您的合成器按键绑定 - 请参阅[按键绑定和 IPC](keybinds-ipc) 指南
4. 通过[主题](application-themes)自定义外观
5. 使用[插件](plugins-overview)扩展功能

有关服务管理、环境变量和更新的详细指导，请参阅[管理您的安装](managing)。

### Systemd 集成（推荐） {#systemd-integration-recommended}

:::tip[DankInstall 用户]

如果您使用了 [dankinstall](../dankinstall)，这已经配置好了。安装程序在设置期间运行 `systemctl --user enable --now dms`。

:::

**启用自动启动：**

```bash
systemctl --user enable dms
```

**手动控制：**

```bash
# Start DMS now
systemctl --user start dms

# Check status
systemctl --user status dms

# View logs
journalctl --user -u dms -f

# Restart DMS
systemctl --user restart dms

# Disable autostart
systemctl --user disable dms
```

:::warning

如果使用 systemd 自动启动，请从合成器配置中删除 `dms run` / `spawn "dms" "run"` / `exec-once=dms run`，以避免运行两个 DMS 实例。

:::

### 特定合成器的 Systemd 设置 {#compositor-specific-systemd-setup}

不同的合成器有不同程度的 systemd 会话集成。选择与您的合成器匹配的章节。

:::tip[为什么使用 add-wants？]

如果您安装了多个桌面环境（例如 Plasma、GNOME、niri），使用 `systemctl --user enable dms` 会在*所有*桌面环境中启动 DMS。使用 `add-wants` 将 DMS 绑定到特定合成器的服务或会话目标，因此它只在您需要的地方运行。当您登录 Plasma 或 GNOME 时，DMS 不会启动。

:::

#### niri {#niri}

niri 具有原生的 systemd 会话集成。将 DMS 绑定到 niri 的服务：

```bash
systemctl --user add-wants niri.service dms
```

DMS 在 niri 启动时启动，在 niri 退出时停止。它不会在其他会话中运行。

#### Hyprland {#hyprland}

Hyprland 默认不初始化 systemd 用户会话。您需要将环境导出到 systemd 才能使 userService 工作。

创建会话目标：

```ini title="~/.config/systemd/user/hyprland-session.target"
[Unit]
Description=Hyprland Session Target
Requires=graphical-session.target
After=graphical-session.target
```

添加到您的 Hyprland 配置中（在任何 `env =` 行之后）：

```conf title="~/.config/hypr/hyprland.conf"
exec-once = dbus-update-activation-environment --systemd WAYLAND_DISPLAY XDG_CURRENT_DESKTOP
exec-once = systemctl --user start hyprland-session.target
```

将 DMS 绑定到会话目标：

```bash
systemctl --user add-wants hyprland-session.target dms
```

#### MangoWC {#mangowc}

[MangoWC](https://github.com/DreamMaoMao/mangowc) 是基于 dwl (wlroots) 的动态平铺合成器。与其他 wlroots 合成器一样，它需要为 systemd 用户服务手动导出环境。

创建会话目标：

```ini title="~/.config/systemd/user/mango-session.target"
[Unit]
Description=MangoWC Session Target
Requires=graphical-session.target
After=graphical-session.target
```

添加到您的 MangoWC 配置中：

```conf title="~/.config/mango/config.conf"
exec-once=dbus-update-activation-environment --systemd WAYLAND_DISPLAY XDG_CURRENT_DESKTOP
exec-once=systemctl --user start mango-session.target
```

将 DMS 绑定到会话：

```bash
systemctl --user add-wants mango-session.target dms
```

#### Sway {#sway}

Sway（基于 wlroots）需要为 systemd 服务导出环境：

```conf title="~/.config/sway/config"
exec dbus-update-activation-environment --systemd WAYLAND_DISPLAY XDG_CURRENT_DESKTOP
```

创建会话目标并将 DMS 绑定到它：

```bash
systemctl --user add-wants sway-session.target dms
```
