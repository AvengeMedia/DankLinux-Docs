DankMaterialShell 可与任何 Wayland 合成器配合使用，但我们为 niri、Hyprland、Sway、MangoWC 和 labwc 提供优化配置。这些配置包括 DMS 特定的键绑定、适当的层 shell 规则和推荐的设置。

## 尼里配置 {#niri-configuration}

niri 使用 KDL 配置格式。 DankMaterialShell 与 niri 的可滚动平铺布局无缝集成。


### 关键配置部分 {#key-configuration-sections}

如果您的 niri 配置中包含以下文件，DMS 将自动应用按键绑定、间隙、窗口半径和颜色。您可以在**设置 → 合成器**中自定义间隙、边框半径和窗口半径。


```kdl
// Add to the end of ~/.config/niri/config.kdl
include "dms/colors.kdl"
include "dms/layout.kdl"
include "dms/alttab.kdl"
include "dms/binds.kdl"
```

:::tip
在将所有文件包含到 niri 配置中之前，请确保所有文件都存在。
```bash
mkdir -p ~/.config/niri/dms
touch ~/.config/niri/dms/{colors,layout,alttab,binds}.kdl
```
:::

有关手动配置建议，请继续下文。

#### 布局 {#layout}

niri 布局应具有透明背景，以便将壁纸集成到概览中。

```kdl
layout {
    // You can tailor the gaps to fit dms spacing.
    gaps 5
    background-color "transparent"
}
```

#### 图层规则 {#layer-rules}

告诉 niri 将壁纸放在概览上。

```kdl
layer-rule {
    match namespace="^quickshell$"
    place-within-backdrop true
}
```

如果启用“模糊图层”，您可以将模糊的壁纸放置在概览上。

```kdl
layer-rule {
    match namespace="dms:blurwallpaper"
    place-within-backdrop true
}
```
有关图层规则的更多信息，请参阅[图层规则](./layers.mdx)。

#### 启动 {#startup}

niri 具有原生的 systemd 会话集成。将 DMS 绑定到 niri 的服务，使其仅在 niri 下运行（不会在 Plasma/GNOME 中启动）：

```bash
systemctl --user add-wants niri.service dms
```

**可选服务：**

```kdl
// Clipboard history
spawn-at-startup "bash" "-c" "wl-paste --watch cliphist store &"
```

**替代方案：直接启动（如果不使用 systemd）**

```kdl
spawn-at-startup "dms" "run"
```

#### 环境变量 {#environment-variables}

```kdl
environment {
  XDG_CURRENT_DESKTOP "niri"
  QT_QPA_PLATFORM "wayland"
  ELECTRON_OZONE_PLATFORM_HINT "auto"
  QT_QPA_PLATFORMTHEME "gtk3"
  QT_QPA_PLATFORMTHEME_QT6 "gtk3"
}
```

#### DMS 键绑定 {#dms-keybindings}

有关可用 IPC 命令的完整列表，请参阅 [IPC](./keybinds-ipc.mdx)

```kdl
binds {
    // Application Launchers
    Mod+Space hotkey-overlay-title="Application Launcher" {
        spawn "dms" "ipc" "call" "spotlight" "toggle";
    }
    Mod+V hotkey-overlay-title="Clipboard Manager" {
        spawn "dms" "ipc" "call" "clipboard" "toggle";
    }
    Mod+M hotkey-overlay-title="Task Manager" {
        spawn "dms" "ipc" "call" "processlist" "focusOrToggle";
    }
    Mod+Comma hotkey-overlay-title="Settings" {
        spawn "dms" "ipc" "call" "settings" "focusOrToggle";
    }
    Mod+N hotkey-overlay-title="Notification Center" {
        spawn "dms" "ipc" "call" "notifications" "toggle";
    }
    Mod+Y hotkey-overlay-title="Browse Wallpapers" {
        spawn "dms" "ipc" "call" "dankdash" "wallpaper";
    }

    // Security
    Mod+Alt+L hotkey-overlay-title="Lock Screen" {
        spawn "dms" "ipc" "call" "lock" "lock";
    }

    // Audio Controls
    XF86AudioRaiseVolume allow-when-locked=true {
        spawn "dms" "ipc" "call" "audio" "increment" "3";
    }
    XF86AudioLowerVolume allow-when-locked=true {
        spawn "dms" "ipc" "call" "audio" "decrement" "3";
    }
    XF86AudioMute allow-when-locked=true {
        spawn "dms" "ipc" "call" "audio" "mute";
    }

    // Brightness Controls
    XF86MonBrightnessUp allow-when-locked=true {
       spawn "dms" "ipc" "call" "brightness" "increment" "5" "";
    }
    XF86MonBrightnessDown allow-when-locked=true {
       spawn "dms" "ipc" "call" "brightness" "decrement" "5" "";
    }
}
```

### 窗口规则 {#window-rules}

推荐的窗口规则，根据您的喜好量身定制：

```kdl
window-rule {
    match app-id=r#"^org\.gnome\."#
    draw-border-with-background false
    geometry-corner-radius 12
    clip-to-geometry true
}

window-rule {
    match app-id=r#"^org\.wezfurlong\.wezterm$"#
    match app-id="Alacritty"
    match app-id="zen"
    match app-id="com.mitchellh.ghostty"
    match app-id="kitty"
    draw-border-with-background false
}

window-rule {
    match is-active=false
    opacity 0.9
}

window-rule {
    geometry-corner-radius 12
    clip-to-geometry true
}

// Open DMS windows as floating by default
window-rule {
    match app-id=r#"org.quickshell$"#
    open-floating true
}
```

## Hyprland 配置 {#hyprland-configuration}

Hyprland 在 `~/.config/hypr/hyprland.conf` 使用简单的配置文件格式。

### 关键配置部分 {#key-configuration-sections-1}

如果您在 Hyprland 配置中包含以下文件，DMS 将自动应用间隙、窗口半径和颜色。您可以在**设置 → 合成器**中自定义间隙、边框半径和窗口半径。

```conf
# Add to the end of ~/.config/hypr/hyprland.conf
source = ~/.config/hypr/dms/colors.conf
source = ~/.config/hypr/dms/layout.conf
source = ~/.config/hypr/dms/outputs.conf
```

:::tip
在将所有文件包含到 Hyprland 配置中之前，请确保所有文件都存在。
```bash
mkdir -p ~/.config/hypr/dms
touch ~/.config/hypr/dms/{colors,layout,outputs}.conf
```
:::

有关手动配置建议，请继续下文。

#### 启动 {#startup-1}

Hyprland 默认不初始化 systemd 用户会话。导出环境并启动会话目标：

```conf
exec-once = dbus-update-activation-environment --systemd WAYLAND_DISPLAY XDG_CURRENT_DESKTOP
exec-once = systemctl --user start hyprland-session.target
```

然后将 DMS 绑定到会话目标，使其仅在 Hyprland 下运行（不会在 Plasma/GNOME 中启动）：

```bash
systemctl --user add-wants hyprland-session.target dms
```

有关创建会话目标的信息，请参阅[安装指南](./installation#hyprland)。

**可选服务：**

```conf
exec-once = bash -c "wl-paste --watch cliphist store &"
```

**替代方案：直接启动（如果不使用 systemd）**

```conf
exec-once = dms run
```

#### 杂项 {#miscellaneous}

禁用 hyprland 背景/徽标

```conf
misc {
    disable_hyprland_logo = true
    disable_splash_rendering = true
}
```

#### 环境变量 {#environment-variables-1}

```conf
env = QT_QPA_PLATFORM,wayland
env = ELECTRON_OZONE_PLATFORM_HINT,auto
env = QT_QPA_PLATFORMTHEME,gtk3
env = QT_QPA_PLATFORMTHEME_QT6,gtk3
```

#### 图层规则 {#layer-rules-1}

```conf
layerrule = noanim, ^(dms)$
```
有关图层规则的更多信息，请参阅[图层规则](./layers.mdx)。

#### 总体布局 {#general-layout}

```conf
general {
    gaps_in = 5
    gaps_out = 5
    border_size = 0

    col.active_border = rgba(707070ff)
    col.inactive_border = rgba(d0d0d0ff)

    layout = dwindle
}
```

#### 装饰 {#decoration}

```conf
decoration {
    rounding = 12

    active_opacity = 1.0
    inactive_opacity = 0.9

    shadow {
        enabled = true
        range = 30
        render_power = 5
        offset = 0 5
        color = rgba(00000070)
    }
}
```

#### DMS 键绑定 {#dms-keybindings-1}

有关可用 IPC 命令的完整列表，请参阅 [IPC](./keybinds-ipc.mdx)

```conf

# Application Launchers

bind = $mod, Y, exec, dms ipc call dankdash wallpaper
bind = $mod, TAB, exec, dms ipc call hypr toggleOverview

# Security
bind = $mod ALT, L, exec, dms ipc call lock lock

# Audio Controls
bindel = , XF86AudioRaiseVolume, exec, dms ipc call audio increment 3
bindel = , XF86AudioLowerVolume, exec, dms ipc call audio decrement 3
bindl = , XF86AudioMute, exec, dms ipc call audio mute

# Brightness Controls
bindel = , XF86MonBrightnessUp, exec, dms ipc call brightness increment 5
```

### 窗口规则 {#window-rules-1}

```conf
# Opacity for inactive windows

# GNOME apps
windowrulev2 = rounding 12, class:^(org\.gnome\.)
windowrulev2 = noborder, class:^(org\.gnome\.)

# Terminal apps - no borders
windowrulev2 = noborder, class:^(org\.wezfurlong\.wezterm)$

# Open DMS windows as floating by default
windowrulev2 = float, class:^(org.quickshell)$
```

## MangoWC 配置 {#mangowc-configuration}

[MangoWC](https://github.com/DreamMaoMao/mangowc)是一个基于dwl(wlroots)的动态平铺Wayland合成器。配置位于 `~/.config/mango/config.conf`。

### 关键配置部分 {#key-configuration-sections-2}

如果您在 MangoWC 配置中包含以下文件，DMS 将自动应用间隙、窗口半径和颜色。您可以在**设置 → 合成器**中自定义间隙、边框半径和窗口半径。

```conf
# Add to the end of ~/.config/mango/config.conf
source=~/.config/mango/dms/colors.conf
source=~/.config/mango/dms/layout.conf
source=~/.config/mango/dms/outputs.conf
```

:::tip
在将所有文件包含到 MangoWC 配置中之前，请确保所有文件都存在。
```bash
mkdir -p ~/.config/mango/dms
touch ~/.config/mango/dms/{colors,layout,outputs}.conf
```
:::

有关手动配置建议，请继续下文。

#### 启动 {#startup-2}

MangoWC 基于 wlroots，需要为 systemd 服务手动导出环境。导出环境并启动会话目标：

```conf
exec-once=dbus-update-activation-environment --systemd WAYLAND_DISPLAY XDG_CURRENT_DESKTOP
exec-once=systemctl --user start mango-session.target
```

然后将 DMS 绑定到会话目标，使其仅在 MangoWC 下运行（不会在 Plasma/GNOME 中启动）：

```bash
systemctl --user add-wants mango-session.target dms
```

有关创建会话目标的信息，请参阅[安装指南](./installation#mangowc)。

**可选服务：**

```conf
exec-once=wl-paste --type text --watch cliphist store
```

**替代方案：直接启动（如果不使用 systemd）**

```conf

```

```conf

focused_opacity=1.0
```

## 其他合成器 {#other-compositors}

DankMaterialShell 可与任何支持以下功能的 Wayland 合成器配合使用：
- Layer shell 协议（用于面板和覆盖层）
- 会话锁定协议（用于锁屏）
- ext-workspace-v1 协议（用于工作区管理）
- wlr-output-management-unstable-v1 协议（用于接口缩放+输出管理）

**注意：** 某些特定于合成器的功能将不可用，例如工作区切换。

### 基本集成 {#basic-integration}

对于其他合成器，您需要：

1. **自动启动DMS：**
   ```bash
   dms run
   ```

2. **使用 [按键绑定和 IPC](keybinds-ipc) 指南中的 IPC 命令配置按键绑定**

3. **在 `~/.config/environment.d/90-dms.conf`（对于 systemd 用户）或您的合成器配置中设置环境变量**：
   ```ini
   QT_QPA_PLATFORM=wayland
   ```

### Sway 示例 {#example-for-sway}

添加到`~/.config/sway/config`：

```conf
# Startup
exec dms run
exec wl-paste --watch cliphist store

# DMS Keybindings
bindsym $mod+space exec dms ipc call spotlight toggle
bindsym $mod+v exec dms ipc call clipboard toggle
bindsym $mod+m exec dms ipc call processlist focusOrToggle
bindsym $mod+comma exec dms ipc call settings focusOrToggle

# Audio controls
bindsym XF86AudioRaiseVolume exec dms ipc call audio increment 3
bindsym XF86AudioLowerVolume exec dms ipc call audio decrement 3
bindsym XF86AudioMute exec dms ipc call audio mute

# Brightness controls
bindsym XF86MonBrightnessUp exec dms ipc call brightness increment 5
bindsym XF86MonBrightnessDown exec dms ipc call brightness decrement 5
```

## 故障排除 {#troubleshooting}

### DMS 不会自动启动 {#dms-doesnt-start-automatically}

检查合成器的日志以确保 `exec-once` 或等效启动命令正在运行。您还可以使用 `dms run` 手动启动 DMS 以查看任何错误消息。

### 按键绑定不起作用 {#keybindings-dont-work}

验证：
- DMS 正在运行 (`pgrep -f "dms run"`)
- 您的键绑定语法与您的合成器的格式相匹配
