# DankSearch {#danksearch}

`dsearch` 是一个本机文件系统搜索工具，具有可配置的索引和 CLI + REST API，用于使用各种参数搜索文件。

## 概述 {#overview}

DankSearch 与 DankMaterialShell 的 Spotlight 启动器无缝集成，提供：

- **即时搜索**：极快的文件系统搜索
- **模糊匹配**：智能搜索，即使有拼写错误也能找到文件
= **内容搜索**：按内容搜索文件，而不仅仅是文件名。
- **高效**：索引按需加载到内存中，而不是无限期地保存在那里。
- **快速**：非常快，适用于数万个文件。
- **零依赖**：零依赖，编译为单个可移植二进制文件。
