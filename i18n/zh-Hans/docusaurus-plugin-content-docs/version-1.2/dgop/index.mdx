# DGOP {#dgop}

`dgop`（Dank GO Process Status）是一个无状态的系统和进程监控工具，提供类似top的tui、CLI和REST API。它允许对与系统相关的大量指标进行采样。

## 特点 {#features}

- 类似顶级的TUI
- CPU、GPU、内存、进程、网络、磁盘和其他各种指标
- 基于游标的无状态方法可在任意时间段内采样数据。
- 完整记录了 OpenAPI 3.1、REST API
- cli 以人类可读或机器可读的格式查询任何指标
- 在单个 `meta` 调用下混合和匹配不同的指标
