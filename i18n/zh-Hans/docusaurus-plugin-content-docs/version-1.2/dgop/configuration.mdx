# DGOP配置 {#dgop-configuration}

## API {#api}

对于 API，您可以设置以下环境变量来覆盖 http 服务器的端口：
- `API_PORT`（默认为`63484`）

## 颜色 {#colors}

dgop 将从 `~/.config/dgop/colors.json` 准备颜色：

示例：

```json
{
  "ui": {
    "border_primary": "#ccbeff",
    "border_secondary": "#cac3dc",
    "header_background": "#ccbeff",
```
