欢迎来到 Dank Linux！本指南将帮助您开始在系统上安装和配置 Dank Linux 套件。

## 快速安装 {#quick-installation}

最快的入门方法是使用我们的单行安装程序：

```bash
curl -fsSL https://install.danklinux.com | sh
```

这将：
- 安装您的发行版的所有依赖项
- 设置 DankMaterialShell、dgop、dsearch、matugen 和其他可选的丰富功能。
- 配置您选择的合成器（niri、Hyprland）和终端（Ghostty、Kitty、Alacritty）

:::tip

安装程序会为您的发行版添加适当的存储库（AUR、COPR、OBS 或 PPA），之后更新将通过常规包管理器进行管理。如果直接从软件包安装 DMS，请运行 `dms setup` 以生成入门合成器和终端配置（仅限 niri/Hyprland）。支持其他合成器，如 sway、MangoWC 和 labwc - 请参阅[手动配置](dankmaterialshell/installation#post-install)。

:::
