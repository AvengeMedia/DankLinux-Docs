The system monitor opens with `dms ipc call processlist focusOrToggle` (bound to <kbd>Super</kbd>+<kbd>M</kbd> in the
default keybinds). Its data comes from [dgop](../dgop/), so it needs dgop installed.

| Page | Shows |
|------|-------|
| Processes | Every process with CPU, memory, GPU, disk and network use. Open a row for its command, details and connections. |
| Performance | CPU, memory, each GPU, drive and network interface with a live chart. |
| Disks | Each drive's health, SMART values, read/write chart and partitions. A sleeping hard drive is never woken up. |
| System | Software, hardware and sensor readings. **Copy system info** copies them as plain text. |

## Ending and restarting processes

Open a process or right-click it for **Quit**, **Force quit**, **End process tree** and **Restart**. Each asks for
confirmation. For the compositor, the user's systemd, the session bus and DMS itself it also warns that this usually
ends the session and offers a restart instead.

| Process | Restart does |
|---------|--------------|
| DMS | `dms restart` |
| Compositor | Reloads its configuration (it can't restart without ending the session) |
| A systemd service's main process | Restarts the service |
| Any other program | Quits it and starts it again with the same command, environment and working directory |
| A program in a terminal | Not available, restart it from the terminal |

## Unlock

Linux only lets the owner or root read a process's disk and network activity, so most values of other users'
processes show `—`. The lock button in the Processes toolbar asks for your password once and then reads every
process as root until you lock it again or close the window. While unlocked, ending another user's process needs no
further password.
