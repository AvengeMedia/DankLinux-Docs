# Changelog

Latest release notes for Dux Shell (DMS). See the full announcements in [updates](/blog).

## DMS v2.0 "Heisenberg"

DankMaterialShell is now Dux Shell. 2.0 brings a Material 3 Expressive redesign, Dash tabs and cards for plugins, a customizable lock screen, and the Dux Lyrical Engine. Plugin authors should update deprecated widget imports and type names. Read the [full announcement](/blog/v2-0-release).

---

## DMS v1.6 "Marble Tabby"

**Released**: 2026-09-03

The fifth major release. Island, a shell-wide performance pass, spring
motion, GTK3 dynamic theming, a standalone greeter, unified versioning across
the desktop suite, and hundreds of fixes. Read the [full announcement](/blog/v1-6-release).

**GitHub Release**: https://github.com/duxlabs-dev/dux-shell/releases/tag/v1.6.0
