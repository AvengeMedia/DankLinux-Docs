The **Network speed monitor** bar widget shows download (`↓`) and upload (`↑`) speed.
The numbers come from [dgop](../dgop/), so the widget needs dgop installed.

Its options are under **Settings → Bar widgets → Network speed monitor**. Both are off
by default, and each widget in a bar keeps its own settings.

## Hide when idle

The widget disappears from the bar while download and upload are both under 1 KB/s.
It leaves no gap, because the widgets on either side close up. It comes back as soon
as either direction reaches 1 KB/s.

The widget keeps reading network speed while it is hidden, at the same rate as when it
is visible.

## Compact mode

Compact mode shows whole numbers, never shows bytes, and moves to the next unit before
a number gets a fourth digit. The widget also takes less room, because it only reserves
space for three digits.

| Speed | Default | Compact mode |
|------|---------|--------------|
| 0 B/s | `0 B/s` | `0 KB/s` |
| 900 B/s | `900 B/s` | `1 KB/s` |
| 3 KB/s | `3.0 KB/s` | `3 KB/s` |
| 1023 KB/s | `1023.0 KB/s` | `1 MB/s` |
| 1.5 MB/s | `1.5 MB/s` | `2 MB/s` |

Any speed above zero shows as at least `1 KB/s`. On a vertical bar the short labels
follow the same rule, for example `999K` and `1M`.

## Using both

Hiding uses the measured speed, not the compact number. At 900 B/s the widget stays
hidden, even though compact mode would show `1 KB/s`.

## Configuration file

Each widget entry in `~/.config/DankMaterialShell/settings.json` stores both options:

```json
{
  "id": "network_speed_monitor",
  "enabled": true,
  "hideWhenIdle": true,
  "compactMode": true
}
```

The entry sits in the `leftWidgets`, `centerWidgets` or `rightWidgets` list of the bar
it belongs to, under `barConfigs`.
