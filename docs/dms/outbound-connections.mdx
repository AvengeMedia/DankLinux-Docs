---
title: Outgoing Connections Inventory
description: Runtime outbound connections initiated by Dux Shell and its components
---

This inventory covers outbound connections initiated by the DMS desktop shell, its Go daemon/CLI, and runtime features shipped in this repository. It excludes installer, packaging, documentation, tests, and example-plugin code. URLs marked dynamic are supplied by settings, media metadata, registry/plugin metadata, the OS, or a remote response; their final hosts cannot be enumerated from this repository alone.

## Scope Notes

- The DMS server also talks to local services and user-selected LAN services (NetworkManager, Tailscale, printers, VPNs, compositor sockets, and similar). This table includes the cases that can target a remote host; routine local IPC is not listed as an internet connection.
- Third-party plugins are executable QML/daemon code. Their network traffic, and traffic from applications/player processes that DMS merely observes through MPRIS, is outside the fixed-URL inventory above.
- URLs in app content or metadata may redirect or reference additional hosts. The table identifies code-defined endpoints and known dynamic URL sources, not every response-dependent CDN hostname. This is a source-based inventory, not a runtime packet capture.
