## Overview

Dux is a modern Linux desktop suite that delivers everything you need in one cohesive package. Built with [Quickshell](https://quickshell.org/) and Go, Dux Shell (DMS) serves as the core desktop shell, providing a unified interface for launching applications, managing windows, system monitoring, notifications, and much more.

## Key Features

- **Full Desktop Shell** - Complete panels, widgets, and system integrations
- **Intelligent Search** - Blazingly-fast file indexing & search with `dsearch`
- **System Monitoring** - Comprehensive system insights with `dgop`
- **Dynamic Theming** - Automatic color generation applied everywhere
- **Plugin System** - Comprehensive plugin system for limitless customization
- **Beautiful by Default** - Stunning desktop experience out of the box

## The Suite

- **[Dux Shell](https://duxlabs.dev/docs/dms/overview)** - Feature-rich desktop shell built with Quickshell and Go
- **[Dux Greeter](https://duxlabs.dev/docs/dms-greeter/)** - An aesthetically pleasing greetd greeter for your desktop
- **[Dux GOP](https://duxlabs.dev/docs/dgop/)** - Stateless, cursor-based system and process monitoring tool
- **[Dux Search](https://duxlabs.dev/docs/dsearch/)** - Extremely fast, configurable filesystem search service
- **[Dux Installer](https://duxlabs.dev/docs/duxinstall)** - Automated installer and management tool for the entire Dux suite
- **[Dux Calendar](https://duxlabs.dev/docs/dcal/)** - Standalone calendar app unifying online and local calendars
- **[Dux Files](https://duxlabs.dev/docs/dfiles/)** - Standalone file manager with tabs, split view, search, trash, devices and network shares
- **[Dux Labs](https://duxlabs.dev/docs/packaging/)** - Pre-built package repositories for major Linux distributions
